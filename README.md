# PROJECTS//ARCHIVE

---

## Overview

 A portfolio like a **digital exhibition**.

Projects are presented through a structured visual grid with large typography, subtle motion, technical metadata, and detailed project views.

The goal is simple:

**Less portfolio. More projects.**

---

## Features

* Curated project archive
* Responsive editorial grid
* Project categories and filters
* Detailed project views
* Project numbering and metadata
* GitHub and live demo links
* Smooth page transitions
* Framer Motion animations
* Hover-based visual interactions
* Responsive mobile layout
* Structured frontend project data
* No backend or database required

---

## Project View

Each project has its own detailed presentation containing:

* Large project preview
* Project description
* Concept / problem
* Technologies
* Key features
* Development highlights
* GitHub repository
* Live demo
* Previous / next project navigation

The project view is designed to feel more like an **interactive case study** than a traditional portfolio page.

##  Getting Started

### Clone the repository

```bash
git clone https://github.com/foulboness/projects-archive.git
cd projectsarchive
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

The application will be available through the local Vite development server.

---

## Production Build

```bash
npm run build
```

Preview the production build with:

```bash
npm run preview
```
